Bu Python programı, basit faiz (Simple Interest) hesaplar.

Kullanım:

1. Terminali açın.
2. `simple_interest.py` dosyasını çalıştırın:
3. Program size anapara, faiz oranı  ve süreyi  soracak.
4. Bu değerleri girdikten sonra program basit faiz miktarını hesaplayacak ve ekrana yazdıracak.

Örnek Çıktı:

Anaparayı girin : 1000 Yıllık faiz oranını girin : 5 Süreyi girin : 3 Basit Faiz: 150.00 TL
